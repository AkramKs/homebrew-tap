# Homebrew Tap for Bitz the Cyber Cat 🐱⚡

Official Homebrew tap for [Bitz](https://github.com/AkramKs/bitz-mac) — the native cyberpunk desktop mascot companion for macOS.

## Installation

```bash
brew install --cask akramks/tap/bitz
```

Or tap first:

```bash
brew tap akramks/tap
brew install --cask bitz
```

## First Launch Note

Because Bitz is distributed directly, on first launch right-click `Bitz.app` and choose **Open**, or run:

```bash
xattr -cr /Applications/Bitz.app
```

## Updating

```bash
brew upgrade --cask bitz
```
